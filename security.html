Demandra / Security Architecture

Enterprise trust, isolation, and compliance.

Retail checkout telemetry contains your most sensitive commercial margin data. Demandra isolates every tenant environment inside dedicated Microsoft Azure envelopes.

01 // TENANT ISOLATION

Zero cross-tenant blending. Full cryptographic separation.

Unlike generic retail analytics platforms that pool merchant transaction histories to train global recommendation models, Demandra provides complete mathematical data isolation.

Your basket volumes, margin profiles, and supplier pricing agreements are stored in dedicated Azure Blob storage containers encrypted with Customer-Managed Keys (CMK).

  • Encryption at Rest AES-256 with Azure Key Vault CMK
  • Encryption in Transit TLS 1.3 (Forced HSTS)
  • Data Sovereignty Azure South Africa North & West Europe
  • Regulatory Standards NDPR / GDPR Aligned / SOC 2 Controls
